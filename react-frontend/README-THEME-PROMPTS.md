
# Indian Wedding Theme Prompts for Image Generation

This document contains all the enhanced prompts for generating Indian wedding theme images using external AI image generation services.

## Available Themes

### 1. Royal Palace/Rajasthani Theme
**Description:** Majestic Rajasthani palace celebrations with royal grandeur, mirror work, and desert charm

**Prompt:**
```
Cinematic wide shot of a magnificent Rajasthani royal palace Indian wedding ceremony. Traditional red sandstone architecture with intricate carved jharokhas and ornate mirror work. Golden mandap decorated with vibrant marigold garlands and roses. Bride in red lehenga with heavy gold jewelry, groom in cream sherwani with kalgi. Traditional Rajasthani musicians playing shehnai and tabla. Warm golden hour lighting, rich red and gold color palette, ultra-detailed, 4K quality, professional wedding photography style.
```

## Usage Instructions

1. **Copy the prompt** for your desired theme
2. **Paste into your preferred AI image generator:**
   - Midjourney
   - DALL-E 3
   - Stable Diffusion
   - Leonardo AI
   - Any other AI image generation service

3. **Optional modifications:**
   - Add specific venue details
   - Adjust lighting preferences
   - Modify color schemes
   - Add regional specifications

4. **Recommended settings:**
   - Aspect ratio: 16:9 or 4:3 for wedding scenes
   - Quality: High/Ultra HD
   - Style: Photorealistic
   - Resolution: 4K when available

## Tips for Better Results

- **Combine prompts:** Mix elements from different themes if needed
- **Add venue context:** Include specific venue types (palace, garden, hotel, etc.)
- **Specify regional details:** Add specific Indian regions or cultural elements
- **Include time of day:** Specify lighting conditions (golden hour, evening, etc.)
- **Add guest count context:** Mention intimate vs. grand celebration scale

## File Locations

After generating your images:
1. Save them in: `react-frontend/public/images/themes/`
2. Update the image paths in: `react-frontend/src/pages/WeddingPreferences.tsx`
3. Use appropriate file names that match the theme IDs
